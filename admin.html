Como Vincular sua Conta e-Rede (Itaú)

  1. Acesse o Portal e-Rede: Entre no site oficial da e-Rede (Userede) e faça login com as suas credenciais.
  2. Localize o Número de Filiação (PV): O PV (Ponto de Venda) é o seu identificador de estabelecimento, visível no canto superior do painel da Rede. Preencha-o no formulário acima.
  3. Gere o Token de Integração: No menu de configurações do portal da Rede, navegue até Integrações > Token de Produção e solicite a geração de um novo Token. Copie e cole no campo acima.
  4. Selecione o Ambiente: Mude para Produção (Real) para começar a transacionar cartões reais de clientes, ou mantenha em Testes (Sandbox) para fazer transações fictícias.
Dica de Segurança: Nunca coloque as credenciais da Rede diretamente no código-fonte das páginas HTML (front-end). O processamento é realizado no Firebase Cloud Functions (back-end) de forma 100% segura para garantir total sigilo dos seus dados de vendas e dos cartões dos alunos.
